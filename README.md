# Quixylon AI Lab

Публичный репозиторий проектов, автоматизаций и экспериментов Quixylon.

## Проекты

| Проект | Описание | Состояние |
| --- | --- | --- |
| [Steam Status Tracker](projects/steam-status-tracker) | Персональная страница, публичный Steam-статус и история активности. | Очистка и проверка; публикация временно остановлена |

## Структура

```text
AI/
├── .github/workflows/   # Автоматические проверки; публикация добавляется отдельно
├── projects/            # Самостоятельные проекты
├── docs/                # Документация и заметки
├── .gitignore
└── README.md
```

## Правила репозитория

- Секреты, токены, пароли и `.env` не коммитятся.
- Каждый проект содержит собственный README и команду проверки.
- Публикация и обновление данных не должны зависеть от временных файлов или конкурирующих workflow.
- Перед слиянием изменений выполняется автоматическая проверка структуры, синтаксиса и данных.
- Рабочие данные не стираются при временной ошибке внешнего API.

## Steam Status Tracker

Во время текущего аудита сайт и обновление Steam остаются остановленными. Сохранены исходники, последняя успешная запись статуса и история активности. Повторный запуск будет выполнен отдельно после успешной проверки чистой версии.
