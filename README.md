# Quixylon AI Lab

Публичный репозиторий проектов, автоматизаций и экспериментов Quixylon.

## Проекты

| Проект | Описание | Состояние |
| --- | --- | --- |
| [Steam Status Tracker](projects/steam-status-tracker) | Персональная страница, публичный Steam-статус и история активности. | Активен |

## Структура

```text
AI/
├── .github/workflows/   # Проверка, обновление Steam и публикация GitHub Pages
├── projects/            # Самостоятельные проекты
├── docs/                # Документация и заметки
├── .gitignore
└── README.md
```

## Правила репозитория

- Секреты, токены, пароли и `.env` не коммитятся.
- Каждый проект содержит собственный README и команду проверки.
- Публикация и обновление данных не зависят от временных файлов или конкурирующих workflow.
- Перед публикацией выполняется проверка структуры, синтаксиса и данных.
- Рабочие данные не стираются при временной ошибке внешнего API.

## Steam Status Tracker

Сайт публикуется через GitHub Pages. Один workflow обновляет Steam примерно раз в пять минут, проверяет проект и публикует каталог `public`.

- Профиль: `https://quixylon.github.io/AI/`
- Трекер: `https://quixylon.github.io/AI/tracker/`
