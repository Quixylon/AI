# Steam Status Tracker

Бесплатный мониторинг одного публичного Steam-профиля на базе **GitHub Pages** и **GitHub Actions**.

Отдельный сервер и база данных для базовой версии не нужны.

## Как это работает

1. GitHub Actions запускается по расписанию примерно раз в 5 минут.
2. Workflow обращается к Steam Web API, используя ключ из GitHub Secrets.
3. Текущий статус и значимые изменения активности записываются в JSON.
4. GitHub Pages публикует статический сайт.
5. Браузер обновляет отображаемые данные примерно раз в минуту без перезагрузки страницы.

Steam API key никогда не попадает в HTML, JavaScript или опубликованные JSON-файлы.

## Возможности

- статус онлайн, офлайн, отошёл, занят и в игре;
- текущая игра, аватар и ссылка на профиль;
- время последней успешной проверки;
- история изменений статуса и игровых сессий;
- уведомления через GitHub Mobile при значимых изменениях;
- адаптивный интерфейс для телефона и компьютера;
- автоматическое сохранение последних успешных данных при временной ошибке Steam API.

## Настройка GitHub

### 1. Включить GitHub Pages

Откройте репозиторий `Quixylon/AI`:

`Settings → Pages → Build and deployment → Source → GitHub Actions`

### 2. Добавить Steam API key

Откройте:

`Settings → Secrets and variables → Actions → Secrets → New repository secret`

Создайте секрет:

```text
Name: STEAM_API_KEY
Secret: ваш Steam Web API key
```

### 3. Указать профиль Steam

Во вкладке `Variables` рекомендуется создать переменную:

```text
Name: STEAM_ID64
Value: 17-значный SteamID64 отслеживаемого профиля
```

Если `STEAM_ID64` не указан, workflow использует vanity-адрес. Его можно изменить отдельной переменной:

```text
Name: STEAM_VANITY
Value: имя из ссылки steamcommunity.com/id/ИМЯ
```

По умолчанию используется `quixylon`.

### 4. Запустить первый раз

Откройте:

`Actions → Steam Status Tracker → Run workflow → Run workflow`

После успешного выполнения сайт появится по адресу:

```text
https://quixylon.github.io/AI/
```

## Уведомления

Issue №1 используется как канал уведомлений. Workflow добавляет комментарий только при входе или выходе из сети, запуске игры либо смене игры. Ошибка отправки уведомления не блокирует обновление и публикацию сайта.

## Расписание

Workflow использует расписание `*/5 * * * *`. GitHub старается запускать его раз в 5 минут, но возможны задержки.

В публичных репозиториях GitHub может отключить scheduled workflows после длительного отсутствия активности. Их можно снова включить в разделе `Actions`.

## Безопасность и приватность

- `STEAM_API_KEY` хранится только в GitHub Secrets.
- Права workflow разделены между сборкой и публикацией.
- Сайт не загружает страницу guns.lol и не отправляет посетителей через сторонний прокси для определения Discord-статуса.
- Счётчик посетителей хранит случайный идентификатор браузера в `localStorage` и отправляет его в настроенный Cloudflare Worker.
- Публично сохраняются данные публичного Steam-профиля и история его активности.

## Ограничения

- отслеживается один Steam-профиль;
- обновление не является мгновенным;
- история хранится в публичном репозитории;
- GitHub Actions и Steam API могут временно задерживать обновления;
- браузерные Web Push-уведомления не используются — уведомления приходят через GitHub Mobile.
