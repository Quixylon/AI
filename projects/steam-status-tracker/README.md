# Steam Status Tracker

Статический сайт профиля Qu’lon и трекер одного публичного Steam-профиля. Интерфейс хранится в `public`, данные Steam — в JSON, а секретный Steam API key используется только серверной автоматизацией GitHub Actions.

## Текущее состояние

Публикация сайта и обновление Steam **намеренно остановлены на время очистки проекта**. Исходники, история активности и последняя успешная запись Steam сохранены. В репозитории остаётся только проверочный workflow, который не публикует сайт и не обращается к Steam API.

## Проверка проекта

Для полной локальной проверки требуется Node.js 20 или новее:

```bash
cd projects/steam-status-tracker
npm run check
```

Проверка выполняет следующее:

- проверяет синтаксис всех JavaScript-файлов;
- разбирает `bio.json`, `status.json` и `history.json`;
- проверяет локальные ссылки из HTML и CSS;
- проверяет обязательные файлы проекта;
- запрещает возвращение временных страниц, старого `profile-v2` и генераторных payload-файлов;
- проверяет последовательность и целостность истории Steam;
- проверяет наличие HTTPS-ссылки на Discord.

## Архитектура после очистки

При повторном запуске будет использоваться один workflow со следующей последовательностью:

1. получить свежий статус Steam;
2. сохранить данные только при реальном изменении;
3. выполнить `npm run check`;
4. загрузить ровно каталог `public` как артефакт GitHub Pages;
5. опубликовать артефакт одним deploy-job.

Отдельные конкурирующие workflow, временные маркеры деплоя и генерация `profile-v2` больше не используются.

## Настройка будущего запуска

В GitHub должны быть сохранены:

```text
Secret: STEAM_API_KEY
Variable: STEAM_ID64
```

`STEAM_ID64` можно не задавать, если используется vanity-адрес `quixylon`. Секрет никогда не должен попадать в HTML, JavaScript, JSON или историю Git.

Перед включением публикации в `Settings → Pages` должен быть выбран источник **GitHub Actions**.

## Данные и приватность

- публично хранятся только данные публичного Steam-профиля и история активности;
- временная ошибка Steam API не стирает последнюю успешную запись;
- счётчик посетителей использует случайный идентификатор браузера в `localStorage`;
- Discord-ссылка ведёт напрямую на профиль и не требует определения статуса;
- сайт не загружает содержимое guns.lol через сторонние прокси.
