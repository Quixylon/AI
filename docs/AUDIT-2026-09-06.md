# Обновление и проверка — 6 сентября 2026

## Что проверено

Текущая структура репозитория, все публичные HTML/CSS/JS и JSON, скрипты Node, workflow GitHub Actions, документация и локальные ссылки. История всех старых коммитов и код внешнего Cloudflare-счётчика не входят в эту проверку.

## Изменения

- Вместо наложенных друг на друга старых оформлений — одна HTML-страница, один stylesheet и именованные модули. Удалены 91 неиспользуемый файл; старые адреса сохранены как перенаправления.
- Новая композиция профиля и трекера, графитовая палитра, светлый акцент, орбитальные линии, частицы и мягкое свечение. Один контроллер отвечает за наклоны. На сенсорных устройствах наклоны отключены, количество частиц и частота отрисовки ограничены. Режим уменьшения движения отключает анимацию.
- Исправлены превращение отсутствующих дат в 1970 год, небезопасные или пустые URL, обработка пустых ответов и отображение отсутствующего счётчика как нуля.
- Исправлена выборка истории: сохраняются свежие записи. Игровые интервалы и присутствие объединяются независимо. Число запусков за сегодня больше не считает всю историю. Прокрутка истории сохраняется при обновлении.
- Отменённый запрос не перезаписывает свежие данные и не сбрасывает новый запрос. Ошибки ручного обновления больше не сопровождаются ложным сообщением об успехе.
- Обновление Steam сохраняет успешные файлы при ошибке API, отказывается перезаписывать повреждённую историю и записывает JSON через временный файл с переименованием.
- Проверка теперь обязательна и при публикации. Pull request не отменяет рабочий деплой; права на запись ограничены соответствующими jobs. Checkout и setup-node обновлены и закреплены по SHA, используется Node.js 24.
- Убраны коммиты только ради отметки сборки; отметка формируется в публикуемом артефакте. Обновлена документация.

## Проверки

`npm run check`: синтаксис, ресурсы, структура и согласованность JSON, 10 регрессионных тестов. Тесты включают отмену запросов, свежесть истории, статистику, 60/144 Гц, ограничения движения, единственный цикл фона и сохранность данных при сбоях Steam.

Браузер: профиль, обзор, Steam, Discord и Telegram; макеты 320, 390, 768 пикселей и ПК; переходы, фильтры и взаимодействия. Это проверка адаптивной компоновки в Chromium, а не испытание на физических iPhone/Android.

## Внешние ограничения

Steam зависит от внешнего API и периодичности GitHub Actions. Discord и Telegram пока не подключены к мониторингу. Счётчик посетителей обслуживается отдельным Cloudflare Worker; его исходников в репозитории нет. Сохранённые данные CSRep не изменены.
