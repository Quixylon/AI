# Дальнейшее развитие

## Реализовано

- Личный профиль, социальные ссылки и переход к трекеру.
- Steam-статус, история игр и сети, статистика за сегодня и семь дней.
- Новый адаптивный интерфейс, мягкие наклоны и динамический фон.
- Поддержка клавиатуры и системного уменьшения движения.
- Проверка проекта и регрессионные тесты перед публикацией.
- GitHub Pages и автоматическое обновление Steam через GitHub Actions.
- Резервная копия до редизайна и совместимость старых адресов.

## Возможные следующие задачи

- Подключить реальные источники Discord и Telegram, когда появятся необходимые интеграции.
- Вынести срок хранения истории в настройку.
- Добавить графики активности, если они окажутся полезны.
- Подключить собственный домен при необходимости.

Это возможные направления, а не уже работающие функции.
